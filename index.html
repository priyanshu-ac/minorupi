MinorUPI API Docs

Reference guide, code examples, webhooks, expiry rules, and AI integration prompt.

1. Introduction & Quickstart▼

MinorUPI lets you accept direct UPI payments via FamApp with exact Decimal matching, zero gateway fees, and real-time HMAC-SHA256 webhooks.

  • Connect your FamApp UPI ID and Gmail App Password in Connect.
  • Generate a server API key in API.
  • Create orders with POST /api/v1/orders and redirect payers to payment_url.
2. Authentication▼

Authenticate backend calls to /api/v1/* with:

Authorization: Bearer upi_live_your_key_here
3. API Endpoints▼

POST /api/v1/orders (Default 5-min expiry)

{
  "amount": 1.00,
  "order_id": "ORD_1001",
  "expiry_minutes": 5,
  "callback_url": "https://yoursite.com/api/webhook",
  "redirect_url": "https://yoursite.com/success",
  "note": "Order #1001"
}

GET /api/v1/orders/{order_id}

GET /api/v1/orders/ORD_1001
Authorization: Bearer <YOUR_API_KEY>

GET /api/v1/orders (List Orders)

GET /api/v1/orders?status=paid&page=1&limit=20
Authorization: Bearer <YOUR_API_KEY>

POST /api/v1/orders/{order_id}/cancel

POST /api/v1/orders/ORD_1001/cancel
Authorization: Bearer <YOUR_API_KEY>
4. Code Examples (cURL / Python / Node.js / PHP)▼

cURL

curl -X POST https://YOUR_GATEWAY/api/v1/orders \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amount": 1.00, "callback_url": "https://yoursite.com/webhook"}'

Python

import requests
r = requests.post("https://YOUR_GATEWAY/api/v1/orders",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={"amount": 1.00, "callback_url": "https://yoursite.com/webhook"})
print(r.json()["data"]["payment_url"])

Node.js

const res = await fetch("https://YOUR_GATEWAY/api/v1/orders", {
  method: "POST",
  headers: { "Content-Type": "application/json", "Authorization": "Bearer YOUR_API_KEY" },
  body: JSON.stringify({ amount: 1.00, callback_url: "https://yoursite.com/webhook" })
});
const { data } = await res.json();

PHP

$ch = curl_init("https://YOUR_GATEWAY/api/v1/orders");
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "Content-Type: application/json",
    "Authorization: Bearer YOUR_API_KEY"
]);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    "amount" => 1.00,
    "callback_url" => "https://yoursite.com/webhook.php"
]));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = json_decode(curl_exec($ch), true);
$payment_url = $response['data']['payment_url'];
5. Webhooks & HMAC-SHA256▼

MinorUPI sends a POST JSON payload with an X-Signature HMAC-SHA256 hex header and retries 3 times on failure.

{
  "order_id": "ORD-12345678",
  "status": "paid",
  "amount": 1.0,
  "base_amount": 1.0,
  "utr": "412345678901",
  "txn_id": "TXN_412345678901",
  "paid_at": "2026-11-18T12:00:00+00:00",
  "created_at": "2026-11-18T12:00:01+00:00",
  "note": "Order #1001"
}
import hmac, hashlib
expected = hmac.new(WEBHOOK_SECRET.encode(), raw_body, hashlib.sha256).hexdigest()
valid = hmac.compare_digest(expected, request.headers.get("X-Signature", ""))
6. Lifecycle & Expiry Rules▼
  • Exact entered amount (`1.00` stays `1.00`) unless another non-expired `pending` order already uses that payable amount.
  • API orders default to 5 minutes; Payment Links use custom minutes. UTC `expires_at` never resets on page refresh.
  • Paid orders never expire; late credits arriving after `expires_at` go to Unmatched credits.
7. FAQ▼

Why did Test verification check Spam & All Mail?
Gmail sometimes routes notification emails outside INBOX; MinorUPI checks INBOX first and falls back read-only to Spam and All Mail.
